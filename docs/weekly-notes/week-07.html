Week 7: Spatial Autocorrelation in Errors

Use residual maps, spatial lags, and Moran’s I to check whether a prediction model is still missing an important pattern about place.
Published

October 16, 2026

What We Did

  1. Reviewed how to read a logged predictor. If X is logged but Y stays in dollars, then beta / 100 is the approximate change in Y for a 1% increase in X.

  2. Moved from census tracts to individual house sales. For point data, we can create spatial features with buffers or nearest neighbors:

    • buffer VS KNN -> spatial lag
    • A buffer can count events within a fixed distance, such as violent crimes within 660 feet.
    • k-nearest neighbors (kNN) can measure the average distance to the nearest events. It can also define the neighbors used for a spatial lag.
    • We should compare these features using cross-validation RMSE.

  3. Cleaned the sales data. Very low sale prices may represent family transfers, sheriff sales, or other non-market transactions, so the cleaning rule must be explained.

  4. Fit a house-price model and calculated the errors:

m1 <- lm(
  sale_price ~ total_livable_area + number_of_bathrooms + age + violent_knn5,
  data = sales
)

sales <- sales %>%
  mutate(
    pred = predict(m1, sales),
    resid = sale_price - pred
  )

A positive residual means the actual price is higher than the predicted price, so the model under-predicted. A negative residual means the model over-predicted.

  1. Map the errors. A residual map helps show where similar errors may cluster. Using alpha and squish keeps overlapping points and very large errors from hiding the main pattern.

  2. Created a spatial lag using the five nearest houses:

coords <- st_coordinates(sales)
w_knn <- nb2listw(
  knn2nb(knearneigh(coords, k = 5)),
  style = "W"
)

sales$resid_lag <- lag.listw(w_knn, sales$resid)

The spatial lag is the average residual of a house’s five nearest neighbors.

  1. Used Moran’s I to measure whether the residuals cluster in space:

\[ I = \frac{n}{\sum_i \sum_j w_{ij}} \frac{\sum_i \sum_j w_{ij}(x_i-\bar{x})(x_j-\bar{x})} {\sum_i(x_i-\bar{x})^2} \]

My short version of the idea is:

  • w_ij -> 1(neighbor); 0(non-neighbor)
  • reference point -> x_i; compare each observation with its neighbors.
  • [-1, 1] -> -1(more sparse); 0(random scatter); 1(cluster) In clearer terms, values near -1 show dispersion, values near 0 show little spatial pattern, and values near 1 show clustering of similar values.
  1. Used a permutation test for significance:
mc <- moran.mc(sales$resid, w_knn, nsim = 499)
mc$statistic
mc$p.value

Significance test: shuffle -> p-value. The test shuffles residuals among houses many times. If the observed Moran’s I is more extreme than almost all shuffled values, the spatial pattern is unlikely to be random.

  1. If Moran’s I is high and significant: the model is probably missing something about place. Possible improvements include a new spatial feature, a neighborhood fixed effect, or an interaction. After adding features, refit the model and compare both CV RMSE and Moran’s I.

Key Concepts

This lecture introduced spatial autocorrelation as a model diagnostic. A residual is actual - predicted, and a residual map shows where the model under-predicts or over-predicts. A spatial lag summarizes nearby values, while Moran’s I measures whether similar residuals are close together. Moran’s I near 1 means clustering, near 0 means little spatial pattern, and below 0 means neighboring values tend to differ. A small p-value tells us the pattern is unlikely to be random, but with a large sample almost everything can be significant, so the size of Moran’s I is also important.

For prediction, we should build spatial features from X variables, such as nearby crime or distance to an amenity, rather than using nearby Y values such as house prices. Using neighbors’ prices can create data leakage during cross-validation.

Reflection

This lecture helped me see that RMSE alone does not show where a model is wrong. Two models can have similar RMSE, but one may have strongly clustered errors. If nearby houses are all under-predicted or all over-predicted, the model is missing some local information. Mapping residuals and calculating Moran’s I therefore gives a clearer way to decide what feature to add next. I also learned that a significant p-value is not enough; the goal is to make Moran’s I smaller while also improving prediction error.

Questions I Still Have

How sensitive is Moran’s I to the choice of neighbors, such as 5-nearest neighbors versus a distance band? How should we choose the spatial weights before comparing models?
