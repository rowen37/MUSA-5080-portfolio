Project overview

Property assessments determine property tax bills, so systematic valuation errors can place an unfair burden on some households. The 2017 Chicago Tribune investigation, “The Tax Divide,” found that lower-value homes in Cook County were often assessed at higher shares of their market value than expensive homes.

In this project, we build a model to predict single-family sale prices in Chicago from 2023 to 2025. We will create spatial features and test whether they improve prediction accuracy and reduce geographic patterns in the errors.

Data and evaluation

We use separate training and test files.

File Role in our project
chicago_train.csv About 80% of the houses, with observed sale prices
chicago_test.csv The remaining houses, without sale prices

Clean only the training sales, build every feature in the same way for both files, and compare models using 10-fold CV RMSE and Moran’s I. Fit the selected model to all cleaned training sales and predict every test house.

Our workflow

We clean and explore the sales, build a structure-only baseline, add spatial and neighborhood features, compare every model in a shared log, map the remaining errors, and examine whether the final predictions are equitable across Chicago neighborhoods.

Define reusable helper functions

Creates shared functions for missing-value checks, consistent 10-fold cross-validation, and Chicago Data Portal downloads.

Code 
check_na <- function(formula, df) {
  vars <- all.vars(formula)
  bad <- vars[sapply(vars, function(v) any(is.na(df[[v]])))]
  if (length(bad) > 0) {
    stop("These variables have NAs: ", paste(bad, collapse = ", "),
         ". Impute them or choose another variable.")
  }
}

# 10-fold CV RMSE, same folds every time
cv_rmse <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  check_na(formula, df)
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm",
               trControl = trainControl(method = "cv", number = 10))
  fit$results$RMSE
}

# Each house's prediction from the fold where it was held out
cv_pred <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  check_na(formula, df)
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm",
               trControl = trainControl(method = "cv", number = 10,
                                        savePredictions = "final"))
  fit$pred %>% arrange(rowIndex) %>% pull(pred)
}

# Chicago Data Portal (Socrata) -> sf. `where` is a SoQL filter.
socrata_get <- function(dataset, where, select = NULL, limit = 200000) {
  where <- str_squish(where)
  q <- paste0("$where=", URLencode(where, reserved = TRUE), "&$limit=", limit)
  if (!is.null(select)) q <- paste0(q, "&$select=", URLencode(str_squish(select), reserved = TRUE))
  url <- paste0("https://data.cityofchicago.org/resource/", dataset, ".geojson?", q)
  tmp <- tempfile(fileext = ".geojson")
  resp <- tryCatch(download.file(url, tmp, quiet = TRUE), error = function(e) e)
  if (inherits(resp, "error")) stop("Portal request failed. Open this URL in a browser to see why:\n", url)
  st_read(tmp, quiet = TRUE)
}

Define a common model-scoring function

Calculates out-of-fold RMSE and Moran’s I from the same residuals for a fair comparison of all candidate features.

Code 
score_model <- function(formula, data, listw) {
  pred <- cv_pred(formula, data)
  resid <- data$sale_price - pred

  tibble(
    cv_rmse = cv_rmse(formula, data),
    moran_i = as.numeric(
      moran(resid, listw, n = length(resid), S0 = Szero(listw))$I
    )
  )
}

```{r}
cv_rmse <- function(formula, data) {

  set.seed(5080)
  fit <- train(formula, data = df, method = "lm",
               trControl = trainControl(method = "cv", number = 10,
                                        savePredictions = "final"))
  fit$pred %>% arrange(rowIndex) %>% pull(pred)
}

# Chicago Data Portal (Socrata) -> sf. `where` is a SoQL filter.
socrata_get <- function(dataset, where, select = NULL, limit = 200000) {
  where <- str_squish(where)
  q <- paste0("$where=", URLencode(where, reserved = TRUE), "&$limit=", limit)
  if (!is.null(select)) q <- paste0(q, "&$select=", URLencode(str_squish(select), reserved = TRUE))
  url <- paste0("https://data.cityofchicago.org/resource/", dataset, ".geojson?", q)
  tmp <- tempfile(fileext = ".geojson")
  resp <- tryCatch(download.file(url, tmp, quiet = TRUE), error = function(e) e)
  if (inherits(resp, "error")) stop("Portal request failed. Open this URL in a browser to see why:\n", url)
  st_read(tmp, quiet = TRUE)
}
```

### Define a common model-scoring function

Calculates out-of-fold RMSE and Moran's I from the same residuals for a fair comparison of all candidate features.

```{r}
#| label: member-1-score-helper
score_model <- function(formula, data, listw) {
  pred <- cv_pred(formula, data)
  resid <- data$sale_price - pred

  tibble(
    cv_rmse = cv_rmse(formula, data),
    moran_i = as.numeric(
      moran(resid, listw, n = length(resid), S0 = Szero(listw))$I
    )
  )
}
```
